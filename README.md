## Latest Research Papers

<!-- PAPERS:START -->
* **[Turns Matter: Advancing Streaming Video RL via Turn-Level Credit](./papers/2026-11-05-turns-matter-advancing-streaming-video-rl-via-turn-level-cre.md)** ([Source](https://huggingface.co/papers/2611.06728))  
  Streaming video understanding requires models to repeatedly decide whether to respond or continue observing. Recently, Group Relative Policy Optimization (GRPO) has been applied to this setting, with existing approaches emphasizing reward design while retaining a single trajectory-level advantage across turns. Such shared credit can reinforce redundant replies after earlier successes and discourage useful follow-ups after earlier failures.

* **[REA: A Routed Embodied Agent Runtime for Asynchronous Brain-Cerebellum Control](./papers/2026-11-05-rea-routed-embodied-agent-runtime.md)** ([Source](https://huggingface.co/papers/rea-routed-embodied-agent))  
  Foundation models are becoming remarkably reliable at high-level reasoning, yet they remain too slow and costly to serve as fine-grained controllers. Conversely, fast policies like VLAs and whole-body controllers offer more efficient reflexes, but struggle to generalize.

* **[FrontierPhysics: Evaluating Agents for End-to-End Physics Research](./papers/2026-11-05-frontierphysics-evaluating-agents-for-end-to-end-physics-res.md)** ([Source](https://huggingface.co/papers/2611.06910))  
  AI agents are playing an increasingly important role in physics research. However, existing physics benchmarks only evaluate fixed questions, isolated sub-tasks, or paper reproduction with given solutions, and rarely check research quality alongside correctness. We introduce FrontierPhysics, an end-to-end benchmark with 56 tasks made by 42 physicists based on their own research, covering nine domains across theoretical, computational, and experimental physics.

* **[From Pixels to Actions - Towards Native Vision-Language-Action Policies](./papers/2026-11-05-from-pixels-to-actions-towards-native-vision-language-action.md)** ([Source](https://huggingface.co/papers/2611.06918))  
  Vision-language-action models are typically built on a simple premise: perception is first compressed by visual encoders, and action reasoning begins only afterwards. Yet manipulation often hinges on precisely the visual signals most vulnerable to this abstraction, e.g., local geometry, boundaries, depth, and subtle state changes. This raises a fundamental question: should action policies inherit a fixed visual endpoint, or directly access evolving visual computation?

* **[Agentic Reasoning in Autonomous Large Language Models](./papers/2026-11-03-agentic-reasoning-autonomous-llms.md)** ([Source](https://huggingface.co/papers/agentic-reasoning-autonomous-llms))  
  A unified framework for multi-step planning, tool execution, and self-correction in autonomous LLM agents operating across long-horizon software engineering tasks.

## Latest Open-Source Models

<!-- MODELS:START -->
* **[ccore/Qwen3.5-4B-3D-Coder](./models/2026-11-06-qwen3-5-4b-3d-coder.md)** ([Source](https://huggingface.co/ccore/Qwen3.5-4B-3D-Coder))  
  Qwen3.5-4B-3D-Coder is a machine learning tasks model from ccore. This is an independent fine-tune by CCORE, based on Qwen/Qwen3.5-4B. It is not an official Qwen release.

* **[Qwen/Qwen2.5-Coder-32B-Instruct](./models/2026-11-05-qwen2-5-coder-32b-instruct.md)** ([Source](https://huggingface.co/Qwen/Qwen2.5-Coder-32B-Instruct))  
  Qwen2.5-Coder-32B-Instruct is a text generation model from Qwen built for code synthesis, code reasoning, and automated debugging across more than 40 programming languages.

* **[Pika-Labs/Pika-H3-Flex](./models/2026-11-05-pika-h3-flex.md)** ([Source](https://huggingface.co/Pika-Labs/Pika-H3-Flex))  
  Pika-H3-Flex is a image-to-video generation model from Pika-Labs. Pika H3 Flex is a post-trained H3 model, designed to give professional creators the flexibility and speed to explore with precision. Optimized for greater control, it generates video with synchronized audio in six sampling steps and supports up to 12 reference inputs, with shot direction through references and prompts.

* **[mistralai/Mistral-Large-4-1T-A52B](./models/2026-11-05-mistral-large-4-1t-a52b.md)** ([Source](https://huggingface.co/mistralai/Mistral-Large-4-1T-A52B))  
  Mistral-Large-4-1T-A52B is a multimodal image and text understanding model from mistralai. Mistral Large 4 is our largest and most capable model to date: a 1 trillion-parameter natively multimodal Mixture-of-Experts model with 49 billion active parameters per token (52 billion including embeddings and output layers), trained from scratch on 3,800 NVIDIA Grace Blackwell GPUs in Mistral's own datacenters in Europe.

* **[moonshotai/Kimi-K3.1-Pro](./models/2026-11-05-kimi-k3-1-pro.md)** ([Source](https://huggingface.co/moonshotai/Kimi-K3.1-Pro))  
  Kimi-K3.1-Pro is a multimodal image and text understanding model from moonshotai. Kimi K3.1 Pro is an open-weight, natively multimodal agentic model, and our most capable 3T-class model to date. Post-trained from Kimi K3 with large-scale joint reinforcement learning across hundreds of downstream domains, it is the first model in the K3.1 series. With a 1-million-token context window, Kimi K3.1 Pro delivers substantial improvements in coding, 3D creation, financial research, factual accuracy, and other agentic capabilities.
