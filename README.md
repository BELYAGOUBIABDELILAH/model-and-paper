## Latest Research Papers

<!-- PAPERS:START -->
* **[Turns Matter: Advancing Streaming Video RL via Turn-Level Credit](./papers/2026-11-05-turns-matter-advancing-streaming-video-rl-via-turn-level-cre.md)** ([Source](https://huggingface.co/papers/2611.06728))  
  Streaming video understanding requires models to repeatedly decide whether to respond or continue observing. Recently, Group Relative Policy Optimization (GRPO) has been applied to this setting, with existing approaches emphasizing reward design while retaining a single trajectory-level advantage across turns. Such shared credit can reinforce redundant replies after earlier successes and discourage useful follow-ups after earlier failures.

* **[REA: A Routed Embodied Agent Runtime for Asynchronous Brain-Cerebellum Control](./papers/2026-11-05-rea-routed-embodied-agent-runtime.md)** ([Source](https://huggingface.co/papers/rea-routed-embodied-agent))  
  Foundation models are becoming remarkably reliable at high-level reasoning, yet they remain too slow and costly to serve as fine-grained controllers. Conversely, fast policies like VLAs and whole-body controllers offer more efficient reflexes, but struggle to generalize.

* **[Agentic Reasoning in Autonomous Large Language Models](./papers/2026-11-03-agentic-reasoning-autonomous-llms.md)** ([Source](https://huggingface.co/papers/agentic-reasoning-autonomous-llms))  
  A unified framework for multi-step planning, tool execution, and self-correction in autonomous LLM agents operating across long-horizon software engineering tasks.

## Latest Open-Source Models

<!-- MODELS:START -->
* **[Qwen/Qwen2.5-Coder-32B-Instruct](./models/2026-11-05-qwen2-5-coder-32b-instruct.md)** ([Source](https://huggingface.co/Qwen/Qwen2.5-Coder-32B-Instruct))  
  Qwen2.5-Coder-32B-Instruct is a text generation model from Qwen built for code synthesis, code reasoning, and automated debugging across more than 40 programming languages.

* **[moonshotai/Kimi-K3.1-Pro](./models/2026-11-05-kimi-k3-1-pro.md)** ([Source](https://huggingface.co/moonshotai/Kimi-K3.1-Pro))  
  Kimi-K3.1-Pro is a multimodal image and text understanding model from moonshotai. Kimi K3.1 Pro is an open-weight, natively multimodal agentic model, and our most capable 3T-class model to date. Post-trained from Kimi K3 with large-scale joint reinforcement learning across hundreds of downstream domains, it is the first model in the K3.1 series. With a 1-million-token context window, Kimi K3.1 Pro delivers substantial improvements in coding, 3D creation, financial research, factual accuracy, and other agentic capabilities.

* **[deepseek-ai/DeepSeek-R1-Distill-Qwen-32B](./models/2026-11-04-deepseek-r1-distill-qwen-32b.md)** ([Source](https://huggingface.co/deepseek-ai/DeepSeek-R1-Distill-Qwen-32B))  
  DeepSeek-R1-Distill-Qwen-32B is a text generation model from deepseek-ai distilled from DeepSeek-R1 to deliver high-efficiency mathematical, code, and logical reasoning.
