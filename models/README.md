* **[ccore/Qwen3.5-4B-3D-Coder](./2026-11-06-qwen3-5-4b-3d-coder.md)** ([Source](https://huggingface.co/ccore/Qwen3.5-4B-3D-Coder))

* **[Qwen/Qwen2.5-Coder-32B-Instruct](./2026-11-05-qwen2-5-coder-32b-instruct.md)** ([Source](https://huggingface.co/Qwen/Qwen2.5-Coder-32B-Instruct))  
  Qwen2.5-Coder-32B-Instruct is a text generation model from Qwen built for code synthesis, code reasoning, and automated debugging across more than 40 programming languages.

* **[Pika-Labs/Pika-H3-Flex](./2026-11-05-pika-h3-flex.md)** ([Source](https://huggingface.co/Pika-Labs/Pika-H3-Flex))  
  Pika-H3-Flex is a image-to-video generation model from Pika-Labs. Pika H3 Flex is a post-trained H3 model, designed to give professional creators the flexibility and speed to explore with precision. Optimized for greater control, it generates video with synchronized audio in six sampling steps and supports up to 12 reference inputs, with shot direction through references and prompts.

* **[mistralai/Mistral-Large-4-1T-A52B](./2026-11-05-mistral-large-4-1t-a52b.md)** ([Source](https://huggingface.co/mistralai/Mistral-Large-4-1T-A52B))  
  Mistral-Large-4-1T-A52B is a multimodal image and text understanding model from mistralai. Mistral Large 4 is our largest and most capable model to date: a 1 trillion-parameter natively multimodal Mixture-of-Experts model with 49 billion active parameters per token (52 billion including embeddings and output layers), trained from scratch on 3,800 NVIDIA Grace Blackwell GPUs in Mistral's own datacenters in Europe.

* **[moonshotai/Kimi-K3.1-Pro](./2026-11-05-kimi-k3-1-pro.md)** ([Source](https://huggingface.co/moonshotai/Kimi-K3.1-Pro))  
  Kimi-K3.1-Pro is a multimodal image and text understanding model from moonshotai. Kimi K3.1 Pro is an open-weight, natively multimodal agentic model, and our most capable 3T-class model to date. Post-trained from Kimi K3 with large-scale joint reinforcement learning across hundreds of downstream domains, it is the first model in the K3.1 series. With a 1-million-token context window, Kimi K3.1 Pro delivers substantial improvements in coding, 3D creation, financial research, factual accuracy, and other agentic capabilities.

* **[deepseek-ai/DeepSeek-R1-Distill-Qwen-32B](./2026-11-04-deepseek-r1-distill-qwen-32b.md)** ([Source](https://huggingface.co/deepseek-ai/DeepSeek-R1-Distill-Qwen-32B))  
  DeepSeek-R1-Distill-Qwen-32B is a text generation model from deepseek-ai distilled from DeepSeek-R1 to deliver high-efficiency mathematical, code, and logical reasoning.
