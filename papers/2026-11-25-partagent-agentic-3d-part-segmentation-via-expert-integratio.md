# PartAgent: Agentic 3D Part Segmentation via Expert Integration and Closed-Loop Refinement

**Link:** [https://huggingface.co/papers/2611.32554](https://huggingface.co/papers/2611.32554)

**Description:** Segmenting a 3D object into semantically meaningful parts requires joint reasoning about geometric structure and semantic context. Pretrained 3D experts provide spatially grounded region proposals, while 2D experts provide semantic cues for identifying object parts. The challenge is to integrate these complementary capabilities into a framework that can both produce meaningful part segmentations and progressively refine them.
