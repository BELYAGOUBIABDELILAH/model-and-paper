# cmHC: Balancing Stream Mixing in Hyper-Connections via Geometric Contraction

**Link:** [https://huggingface.co/papers/2611.27193](https://huggingface.co/papers/2611.27193)

**Description:** Manifold-constrained Hyper-Connections (mHC) extends residual connections to multiple streams and stabilizes residual propagation by constraining stream-mixing residual matrices to the Birkhoff polytope, the set of doubly stochastic matrices. In this work, we investigate how to effectively mix residual streams within the Birkhoff polytope.
