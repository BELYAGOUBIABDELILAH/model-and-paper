# Gamer: A Generalist Vision-Language-Action Foundation Model for Long-Horizon Real-Time Game Agent

**Link:** [https://huggingface.co/papers/2611.18397](https://huggingface.co/papers/2611.18397)

**Description:** We introduce Gamer, a generalist agent framework built for long-horizon tasks in complex interactive environments. Its end-to-end architecture combines perception, memory management, and multi-step reasoning. A shared training and deployment pipeline supports interaction with both conventional 2D graphical interfaces and complex 3D simulated worlds.
