# Tree-Ising: Repairing Language Models with Bit-Level Ising Edits

**Link:** [https://huggingface.co/papers/2611.14210](https://huggingface.co/papers/2611.14210)

**Description:** Weight-space programming, introduced in recent MIT work by Takehi et al., enables a frontier LLM agent to read a network's weights and write a repair. Their GPT-6 Astra agent corrected the reasoning loops of Qwen3.5-0.8B without gradients, using 158 agent turns, 89.7 million tokens, and 50 forward-pass requests. Our method, Tree-Ising, casts this repair as a sparse discrete optimization problem over the model's own BF16 weights.
