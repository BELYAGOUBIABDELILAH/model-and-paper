# SLA: Scaling Spatial-Language-Action Model via Continual Pre-training

**Link:** [https://huggingface.co/papers/2611.08373](https://huggingface.co/papers/2611.08373)

**Description:** Reliable robotic manipulation requires both semantic understanding and precise control in three-dimensional space. However, vision-language-action (VLA) foundations largely inherit visual representations from 2D vision-language pre-training, while spatial supervision is often introduced only during task-specific adaptation. Developing spatial understanding as a transferable foundation-model capability therefore calls for learning from broader robot experience.
