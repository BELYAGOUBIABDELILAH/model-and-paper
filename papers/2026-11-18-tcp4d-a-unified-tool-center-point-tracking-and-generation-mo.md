# TCP4D: A Unified Tool-Center-Point Tracking and Generation Model for Robot Manipulation

**Link:** [https://huggingface.co/papers/2611.23143](https://huggingface.co/papers/2611.23143)

**Description:** Robot manipulation videos provide a rich visual experience, yet recovering robot action and gripper-state annotations from RGB observations still remains challenging. Using the embodiment-agnostic tool-center-point (TCP) pose as the action space, we present TCP4D, a unified model in which a shared 4D scene representation both tracks observed TCP motion and generates future TCP trajectories.
