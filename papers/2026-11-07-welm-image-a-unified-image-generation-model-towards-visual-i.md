# WeLM-Image: A Unified Image Generation Model towards Visual Intelligence

**Link:** [https://huggingface.co/papers/2611.07392](https://huggingface.co/papers/2611.07392)

**Description:** We present WeLM-Image, a unified image foundation model that integrates multimodal understanding into text-to-image generation, instruction-guided editing, and multi-reference synthesis. Designed for single-GPU deployment in WeChat's large-scale consumer applications, the model processes text, reference images, and target latents as one interleaved sequence. A Mixture-of-Transformers (MoT) backbone combines shared attention with independent understanding and generation parameters to limit optimization interference.
