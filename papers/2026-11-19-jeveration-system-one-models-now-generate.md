# Jeveration: System One Models Now Generate

**Link:** [https://huggingface.co/papers/2611.24738](https://huggingface.co/papers/2611.24738)

**Description:** System One models such as Jev return decisions through fast, parallel prediction. In this paper, we introduce Jeveration, showing that the same decision paradigm can also generate high-quality images in a single forward pass. Jeveration builds on a frozen vision-language model, repurposing its visual-semantic knowledge for holistic image generation.
